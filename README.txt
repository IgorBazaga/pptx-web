POWER CONTROL REMOTE PPTX

Como rodar:
1. Extraia o ZIP
2. Abra a pasta no VS Code
3. No terminal:
   npm install
   npm start

Links:
VIEW/TELÃO: http://localhost:3000
EDITOR:     http://localhost:3000/editor
CONTROLE:   http://localhost:3000/control

No celular, use o IP que aparece no terminal, exemplo:
http://192.168.0.15:3000/control

IMPORTANTE SOBRE PPTX:
Para o PPTX abrir preservando o visual, instale o LibreOffice no Windows.
O sistema usa o LibreOffice apenas para converter o PPTX em PDF localmente e exibir sem reconstruir o layout.
PDF pode ser importado direto.

Não vem com slides pré-definidos.
